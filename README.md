# 💻 My React Projects Collection

Welcome to my collection of mini React.js applications! Each project in this repository is built to solve real-world problems with a clean and modern UI. Explore the folders to find different apps, each focused on specific functionality.

---

## 📁 Projects

### 🔹 [calculator](./calculator)
A simple and responsive calculator built using React. Features:
- Basic arithmetic operations
- Keyboard input support
- Neat UI with modern design

### 🔹 [story-app](./story-app)
A mini Wattpad-like platform that lets users:
- Add and read short stories
- View stories in list format
- Built with component-based architecture

### 🔹 [voice-app](./voice-app)
A voice-to-text and text-to-speech converter app:
- Uses Web Speech API
- Type text and listen with speech synthesis
- Speak and convert to editable text


### 🔹 [Water_Reminder](./Water_Reminder)
A Progressive Web App (PWA) that reminds users to stay hydrated. Features:
- Customizable timer settings
- Desktop notifications
- Clean and minimal UI
- Fully offline support

---

## 🛠️ Tech Stack

- React.js
- HTML, CSS
- JavaScript
- PWA (for Water Reminder)
- Web Speech API (for voice-app)

---

## 🧠 Inspiration

These projects were developed to practice React concepts and solve small yet meaningful problems like hydration tracking, creative writing, basic computation, and voice accessibility.
